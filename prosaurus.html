Prosaurus

A full-stack social productivity platform — web, mobile, and everything in between

Prosaurus is an in-house project that serves as both a real-world product and a living demonstration of what Cherry Blossom Development builds. It is a social productivity platform designed for teams and communities — combining real-time messaging, content sharing, and user management into a single cohesive experience.

The project spans every layer of modern software: a cloud-deployed backend, a responsive web client, a native Android app, an iOS app in development, and a fully automated test suite that exercises all of it. Every component is built, deployed, and maintained by the Cherry Blossom Development team.

Platform Overview

Web Application

The Prosaurus web app is a single-page application built with Vue 3. It delivers a fully responsive experience in the browser, with real-time updates powered by Socket.IO. Users can manage profiles, participate in group discussions, exchange direct messages, and interact with a customizable dashboard of content widgets.

  • Vue 3 with Vite
  • Pinia for state management
  • Socket.IO for real-time messaging
  • Deployed as static files via nginx on AWS EC2

Android App

The Android application is built natively in Kotlin using Jetpack Compose for the UI. It connects to the same backend API as the web app, giving users the full Prosaurus experience on their Android devices. Authentication uses encrypted local storage, and all network communication is secured over HTTPS.

  • Kotlin with Jetpack Compose
  • Retrofit for type-safe API calls
  • Coroutines for async operations
  • EncryptedSharedPreferences for secure token storage
  • Available on Google Play

iOS App

An iOS companion to the Android app is currently in development. It will share the same backend API and feature parity with the Android and web clients, giving Prosaurus users a native experience across all major mobile platforms.

  • Native Swift development
  • SwiftUI interface
  • Shared backend API with Android and web
  • Coming to the App Store

Backend & Infrastructure

All three clients are powered by a single backend API built on Node.js and Express, running inside a Docker container on an AWS EC2 instance. A Redis pub/sub adapter enables Socket.IO to broadcast real-time events across multiple server instances, laying the foundation for horizontal scaling. nginx handles SSL termination and routes traffic between the static frontend and the backend container.

Key backend technologies

  • Node.js + Express REST API
  • MariaDB for persistent data storage
  • Socket.IO with Redis adapter for real-time communication
  • Docker for containerized backend deployment
  • nginx as reverse proxy with Let’s Encrypt SSL
  • AWS EC2 hosting

Automated Testing

Prosaurus includes a dedicated end-to-end test suite that covers both the web and Android clients. Tests run against an isolated test database with seeded users and known state, so each run is clean and repeatable. The test infrastructure is maintained alongside the product code and is run continuously as new features are developed.

Testing stack

  • WebdriverIO as the primary test framework
  • Appium for Android device automation
  • Mocha test runner with structured reporting
  • Isolated breakroom_test database with schema kept in sync from production
  • Page object model for maintainable, reusable selectors
  • Tests cover authentication, navigation, real-time messaging, and user management flows
